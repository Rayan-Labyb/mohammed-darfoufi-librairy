    Catalog guide

    How to add a book students will actually find.

    1. Match the printed copy. Use the title, author, and ISBN printed on the book — not the site title.
    2. Verify the ISBN-13. The 13-digit barcode printed on the book. Use the Auto-fetch button to pull cover and info.
    3. Find the place. Scan the physical column sign (1–6) and the shelf tier (A top → D bottom).
    4. Write a warm overview. Two to four sentences a student can skim in a few seconds.
    5. Save, then spot-check. Search the new book on the dashboard and preview it like a student would.

    How the library works

    1. Search or explore. Type a title, an author, or an ISBN — or tap a category chip.
    2. Read the location label. Each book shows a code like B3 — the letter is the shelf, the number is the column.
    3. Walk it. Columns 1–6 match the aisle signs; shelves A–E run top to bottom, so the signs read A1–A6, B1–B6 … E1–E6.
    4. Lost? Ask Duaa & Rayan at the library desk — they will find it with you.
